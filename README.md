# 🎨 SHANI Art

A responsive artist portfolio, gallery, commission, and storefront experience built with HTML, CSS, and JavaScript.

SHANI Art is a web project designed to provide artists with a clean digital space to showcase their work, accept commission enquiries, display artwork collections, and present products through an elegant and responsive interface.

---

## ✨ Features

- 🎨 Artist portfolio and artwork showcase
- 🖼️ Responsive image gallery
- 🛍️ Artwork and product storefront
- ✏️ Commission information and booking flow
- 👩‍🎨 Artist profile and About section
- 📩 Contact and enquiry forms
- 📱 Responsive navigation and mobile-friendly layout
- 🎬 Video-based hero experience
- 🛒 Interactive frontend shopping experience
- ⚡ Lightweight implementation with no heavy framework dependencies

---

## 🧰 Technology Stack

The project currently uses:

- **HTML5** — page structure and semantic markup
- **CSS3** — responsive layouts, styling, typography, and animations
- **JavaScript** — interactions and frontend functionality
- **Google Fonts** — web typography
- **Git & GitHub** — source control and project collaboration

The project intentionally uses a lightweight frontend architecture so it can be easily understood, modified, and extended.

2. Open the project

3. Run locally

No build process is currently required.
